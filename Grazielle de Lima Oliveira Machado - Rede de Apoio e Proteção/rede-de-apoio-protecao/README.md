# Rede de Apoio e Proteção — versão organizada em pastas

Projeto de Grazielle de Lima Oliveira Machado, separado conforme o README do grupo:

```
rede-de-apoio-protecao/
├── index.html             estrutura e conteúdo dos slides
├── css/style.css          cores, tipografia, layout, responsividade
├── js/tailwind-config.js  cores e fontes da identidade visual (Tailwind)
├── js/script.js           navegação, contador, gráficos ECharts, tooltips, imagens
├── assets/images/         imagens da apresentação
└── assets/icons/          ícones próprios
```

Para abrir, dê dois cliques em `index.html` (precisa de internet para Tailwind, ECharts e Font Awesome).
O arquivo original, com tudo junto, continua na pasta da aluna.
